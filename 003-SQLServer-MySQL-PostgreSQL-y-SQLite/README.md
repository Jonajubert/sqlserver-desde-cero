# SQL Server, MySQL, PostgreSQL y SQLite

Ya sabemos qué es una base de datos y qué función cumple un motor de base de datos.

Ahora conoceremos cuatro de los motores más utilizados en la actualidad.

---

#  ¿Qué aprenderás?

- Qué es SQL Server.
- Qué es MySQL.
- Qué es PostgreSQL.
- Qué es SQLite.
- Cuándo conviene utilizar cada uno.

---

# Comparativa

| Motor | Desarrollador | Ideal para |
|--------|---------------|------------|
| SQL Server | Microsoft | Empresas, .NET, Power BI, Azure |
| MySQL | Oracle | Sitios web, WordPress, PHP |
| PostgreSQL | PostgreSQL Global Development Group | Aplicaciones empresariales, análisis de datos |
| SQLite | SQLite Consortium | Aplicaciones móviles, escritorio y proyectos pequeños |

---

# SQL Server

### Ventajas

- Excelente integración con .NET.
- Herramientas muy completas.
- Alto rendimiento.
- Muy utilizado en empresas.

---

# MySQL

### Ventajas

- Fácil de aprender.
- Gran comunidad.
- Muy utilizado en aplicaciones web.
- Amplia documentación.

---

# PostgreSQL

### Ventajas

- Muy potente.
- Excelente soporte para SQL.
- Gran rendimiento.
- Muy utilizado en sistemas complejos.

---

# SQLite

### Ventajas

- No requiere servidor.
- Toda la base de datos se guarda en un único archivo.
- Muy liviano.
- Ideal para aplicaciones móviles y de escritorio.

---

# ¿Cuál debería aprender primero?

Si trabajás con tecnologías Microsoft o querés desarrollar aplicaciones en C#, SQL Server es una excelente opción para comenzar.

Más adelante será mucho más sencillo aprender otros motores como MySQL o PostgreSQL, ya que comparten gran parte del lenguaje SQL.

---

# 💡 ¿Sabías que?

Aunque cada motor tiene sus propias características, las consultas básicas (`SELECT`, `INSERT`, `UPDATE` y `DELETE`) son muy similares entre ellos.

Por eso, aprender SQL facilita el trabajo con distintos motores de bases de datos.
