## ¿Qué es una Base de Datos?

Una base de datos es un conjunto de información organizada que permite almacenar datos de forma estructurada.

Gracias a una base de datos podemos:

- Guardar información.
- Buscar información rápidamente.
- Modificar registros.
- Eliminar datos.
- Compartir información entre varias aplicaciones.

---

## Ejemplos

Una escuela puede almacenar:

- Alumnos
- Profesores
- Materias
- Calificaciones

Un comercio puede almacenar:

- Productos
- Clientes
- Ventas
