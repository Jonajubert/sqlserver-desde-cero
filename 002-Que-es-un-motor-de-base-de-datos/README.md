# ¿Qué es un motor de base de datos?

Un motor de base de datos es el software encargado de administrar una base de datos.

Su trabajo consiste en almacenar, consultar, actualizar y proteger la información.

## Funciones principales

- Almacenar datos.
- Ejecutar consultas.
- Administrar usuarios.
- Controlar permisos.
- Optimizar el rendimiento.
- Garantizar la integridad de los datos.

## Ejemplos de motores

- SQL Server
- MySQL
- PostgreSQL
- SQLite
- Oracle Database

## Ejemplo

Cuando una aplicación solicita la información de un cliente, el motor recibe la consulta, busca los datos dentro de la base de datos y devuelve el resultado.
